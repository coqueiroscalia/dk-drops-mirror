# dk-drops-mirror

Ephemeral public mirror used to host media files temporarily so that third-party
publishing platforms (Buffer, etc.) can ingest them via public URL.

Files in releases are short-lived: typically uploaded, ingested by the target
platform within minutes, then deleted from this repo. The repo itself contains
no source code or sensitive content.

Tooling: see [`coqueiroscalia/dk-video`](https://github.com/coqueiroscalia/dk-video).
